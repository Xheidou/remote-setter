Importer un fichier personnalisé

Fichier JSON produit par scripts/build_board_data.py --out fichier.json, ou au format ci-dessous. Les boards déjà connues gardent leur géométrie réelle si le fichier n'a pas les contours des prises.

{
  "format": 2,
  "boards": [{
    "id": "kilter-original", "name": "…",
    "width": 3.658, "panel": 3.658,
    "kicker": [0.46, 0.46, 0.91],
    "angles": {"min": 0, "max": 70, "step": 5, "def": 40},
    "holes": [[id, x, y, teinte, type, orientation, pied], …],
    "outlines": {"id": [x0, y0, x1, y1, …]}
  }],
  "climbs": [{
    "id": "…", "board": "kilter-original", "name": "…",
    "setter": "…", "grade": "6b/V4", "angle": 40,
    "stats": [[angle, cotation, répétitions, qualité]],
    "holds": [[id, "start"|"hand"|"finish"|"foot"], …]
  }]
}

Mètres. x depuis le bord gauche ; y le long du panneau depuis la charnière (négatif = sur le kicker). Contours relatifs au boulon de la prise.

Clic sur une prise : hauteur depuis le tapis et distance à la prise précédente. Glisser pour tourner, molette ou pincement pour zoomer. Géométrie et contours : Boardsesh (Apache-2.0). Blocs : snapshots publics Boardsesh, créés par les ouvreurs crédités. Types de prises : CruxCoach (CC BY 4.0), étiquettes en cours de validation par leur projet.
